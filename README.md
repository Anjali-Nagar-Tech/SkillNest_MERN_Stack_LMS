# SkillNest - MERN Stack Learning Management System

## 📚 Overview

SkillNest is a full-stack Learning Management System (LMS) built using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). The platform is designed to provide an interactive online learning experience where students can explore courses, enroll in programs, and track their learning journey, while instructors can manage educational content efficiently.

This project demonstrates modern full-stack web development practices including RESTful APIs, authentication, state management, database integration, and responsive UI development.
